## Customization

I added personal touches to the game to give it its own identity while still using the Breakout tutorial as the foundation.

My customizations include:

* Custom colors
* Custom brick colors
* A custom game background
* A life score
* A custom game-over screen

These additions helped make the game feel more like my own project while demonstrating that I followed the tutorial and understood the development process.

If I were to continue developing the game, I would add a more challenging gameplay mechanic. One feature I would consider adding is the ability to control two platforms instead of one. This would add another level of difficulty and require the player to manage two platforms at the same time.
